# AVault

AVault 是一套由 Windows 桌面端和 Android 客户端组成的个人局域网媒体库。桌面端负责扫描和整理本机影片、维护影片与演员资料、调用 PotPlayer 播放，并提供 FFmpeg 媒体检测、HEVC 转码、影片预览图和独立视频工具箱；Android 端通过扫码与桌面端配对，在局域网内浏览和播放电脑上的影片。

AVault 仅面向本地电脑和局域网使用，不提供资源下载、磁力链接、云同步或公网媒体分享。

Windows 桌面端与 Android 局域网客户端的首个可用版本均已完成。

当前仓库包含：

- `electron/`：Electron、React、TypeScript 桌面端，同时提供带令牌鉴权的局域网服务。
- `android/`：Kotlin、Jetpack Compose、Media3 Android 客户端。
- `javdb-copy-title-and-metadata.user.js`：用于复制 JavDB 影片资料 HTML 的 Tampermonkey 脚本。
- `REQUIREMENTS.md`：桌面端实现基线。
- `android/REQUIREMENTS.md`：Android 端需求与验收基线。

## 1. 系统要求

- Windows 10 或 Windows 11（64 位）。
- 推荐安装 PotPlayer，用于桌面端播放影片。
- 如需媒体参数检测、影片预览图或转码，请安装 FFmpeg，并确保 `ffmpeg.exe` 和 `ffprobe.exe` 可以通过系统 `PATH` 调用。
- HEVC 转码需要支持 NVENC 的 NVIDIA 显卡，以及 FFmpeg 中可用的 `hevc_nvenc` 编码器。
- JavBus、FC2、演员头像和 AI 资料功能需要网络连接；本地扫描与播放不需要联网。

## 2. 安装与升级

运行 Windows 安装包：

`electron/release/AVault Setup 0.1.0.exe`

安装时可以选择程序目录。AVault 会自动在程序所在磁盘的根目录创建独立数据目录：

- 安装到 C 盘：`C:\AVault-data`
- 安装到 D 盘：`D:\AVault-data`
- 安装到 E 盘：`E:\AVault-data`

升级安装只替换程序文件，不会删除该目录中的数据库和设置。请不要手动删除 `AVault-data`。

如果以后把 AVault 改装到另一块磁盘，程序会使用新磁盘根目录下的 `AVault-data`；旧磁盘的数据不会自动迁移。

## 3. 首次使用

1. 打开 AVault。程序默认最大化启动，关闭窗口后会缩到系统托盘。
2. 点击左侧的“添加媒体文件夹”，选择一个或多个影片根目录。
3. 根据目录内容设置“默认片源分区”，也可以保留“自动判断”。
4. 点击“重新扫描”，等待 AVault 建立文件索引并读取媒体参数。
5. 扫描只识别本地文件，不会自动联网获取影片资料。
6. 在影片详情页单独爬取资料，或在媒体文件夹页面使用“批量爬取”。

首次启动局域网服务时，Windows 防火墙可能询问是否允许访问。仅需允许专用网络。

## 4. 文件名与番号识别

AVault 优先从文件名识别番号，识别失败时会尝试父目录名。建议使用清晰、稳定的命名方式：

```text
SSIS-826.mp4
FC2-PPV-1234567.mp4
TH101-140-112594.mp4
031515-828-C.mp4
```

常见附加标记：

- `-CD1`、`-CD2`、`-PART1`：同一影片的分段文件。
- `[HEVC]`：HEVC 原分辨率版本。
- `[720p HEVC]`：手机使用的 720p HEVC 版本。
- `-C`：中文字幕标记；日期型无码番号中的该后缀不会计入番号。

同一番号的原片、分段和不同转码版本会归入同一部影片。无法识别的文件可以在左侧“未识别”页面查看，再进入详情页手动修改番号。

## 5. 片源分区

影片分为以下片源分区：

- 有码
- FC2
- 无码
- 流出
- 待分类

分区判断优先级为：影片手动设置、本地 `.avault.json`、媒体文件夹默认分区、文件名规则、待分类。

“流出”不会仅凭普通有码番号自动判断。建议为专门存放流出影片的媒体文件夹设置默认分区。

影片分区和来源会同时保存到 SQLite 与影片同级的 `.avault.json`。

## 6. 浏览媒体库

“全部影片”和媒体文件夹页面支持：

- 按番号、标题或演员搜索。
- 按片源分区和观看状态筛选。
- 按添加时间、发行日期、番号或标题排序。
- 横向封面、竖向封面和列表三种视图。
- 记住上次选择的排序、观看状态和视图偏好。
- 右键影片，在资源管理器中显示文件位置。

卡片上的播放按钮会直接调用 PotPlayer；点击卡片主体进入影片详情页。

## 7. 影片详情与播放

详情页会展示番号、发行日期、时长、导演、制作商、发行商、系列、演员、标签、简介、观看状态以及所有本地文件。

每个本地文件会显示：

- 容器和视频编码。
- 分辨率与帧率。
- 视频码率、音频编码和声道。
- 文件大小、可用状态和版本类型。

“使用 PotPlayer 播放”默认优先选择原片。存在多个无法自动决定的原片时，AVault 会要求选择具体文件。

如果没有检测到 PotPlayer，可以在“设置”中手动选择 `PotPlayerMini64.exe`。

## 8. 获取和编辑影片资料

### JavBus

- 有码影片使用 JavBus 有码搜索。
- 无码影片必须先设置为“无码”，AVault 才会使用 JavBus 无码搜索入口。
- 搜索后先显示候选结果，确认后再读取完整详情与封面。
- 批量爬取会逐部保存成功结果，并加入随机间隔与连续失败保护。

JavBus 返回 403 时通常是来源网站暂时限流。请停止频繁请求，稍后再试。

### FC2

标准番号格式为 `FC2-PPV-数字`。FC2 影片使用 FC2 商品页获取资料。

如商品页要求登录，请在设置中粘贴浏览器中的 FC2 Cookie。Cookie 保存在本机，不会上传到 AVault 之外的服务。

### JavDB 本地 HTML

AVault 不自动登录或请求 JavDB。需要使用时：

1. 在浏览器打开对应影片详情页。
2. 复制页面 HTML。
3. 在详情页点击“编辑资料”。
4. 使用“读取剪贴板并解析”。
5. 检查解析结果后保存。

该功能只解析文字资料，不自动下载 JavDB 图片。

### Tampermonkey 辅助复制

仓库根目录的 `javdb-copy-title-and-metadata.user.js` 可配合上述流程使用：

1. 安装 Tampermonkey 扩展，并导入该 `.user.js` 文件。
2. Chrome 用户还需在 Tampermonkey 的扩展详情页启用“允许运行用户脚本”。
3. 打开 JavDB 的影片详情页（`/v/*`），点击新增的“复制信息”按钮。
4. 回到 AVault 的“编辑资料”页面，使用“读取剪贴板并解析”。

脚本会复制影片标题和元数据面板的 HTML；同时将封面图片从外层链接中移出，因此封面不再可点击打开原图。JavDB 页面结构变动时，脚本的选择器可能需要同步调整。

### 手动编辑

点击“编辑资料”可以修改所有影片字段和片源分区。手动填写且已有内容的字段不会被普通资料补全操作覆盖。

## 9. 封面与本地 JSON

将鼠标移到详情页封面上，会显示：

- 查看原图
- 编辑封面
- 删除封面

编辑封面弹窗支持选择图片、拖入图片和直接粘贴剪贴板图片。

影片封面保存在影片文件同级目录，通常命名为：

```text
番号.avault-cover.jpg
```

“写入本地 JSON”会为影片生成同级 `.avault.json`，保存影片资料、演员、标签、片源分区和封面文件名。即使数据库需要重建，重新扫描时也可以从这些文件恢复资料。

建议在完成重要资料编辑后执行一次“写入本地 JSON”。

## 10. 演员库

左侧“演员库”会汇总媒体库中的全部演员。点击演员可查看资料和参演影片，并按观看状态、发行日期等条件筛选。

- 演员头像从 Gfriends 获取。
- 头像支持查看、替换、粘贴和删除。
- “AI 更新资料”使用 DeepSeek 整理公开网页结果。
- AI 可保存别名、生日、年龄、身高、三围、出道年份和社交媒体主页。
- 社交媒体链接会通过 Windows 默认浏览器打开。

DeepSeek API Key 和 Token 统计位于左侧“AI 中心”。AI 请求、原始返回和公开来源可以在“运行日志”中查看。

## 11. 影片预览图

详情页可使用 FFmpeg 生成影片预览图：

- 从影片的 6 个均匀位置截取画面。
- 合成为一张 `3 × 2` 图片。
- 保存到原片同级目录：`原文件名.avault-preview.jpg`。
- 点击预览图可以全屏查看。
- 在查看界面滚动鼠标滚轮，可在 50% 到 300% 之间缩放。
- 可以重新生成或删除预览图。

生成和删除预览图不会修改原片或影片封面。

## 12. HEVC 转码

详情页提供两种转码：

- “转码高清 HEVC”：保持原始分辨率，生成 `[HEVC].mp4`。
- “转码 720p HEVC”：最高 720p，不放大低分辨率片源，生成 `[720p HEVC].mp4`。

转码默认使用 NVIDIA NVENC、H.265、8-bit `yuv420p`、`hvc1` 标记和 AAC 双声道。多个任务会进入队列，同一时间只运行一个 FFmpeg 工作。

左侧“任务”页面可以查看进度、速度、预计剩余时间，并可取消或移除任务。

“用此 HEVC 版替换原片”会永久删除原片，并将高清 HEVC 版设为主文件。该操作不可恢复，请确认转码文件可以正常播放后再执行。720p 版本不会用于替换原片。

## 13. 整理媒体库

媒体文件夹页面的“整理媒体库”会先生成预览，不会立即移动文件。默认目标结构为：

```text
媒体根目录/演员名/番号/影片文件
```

规则如下：

- 多演员影片使用演员列表第一位。
- 无演员资料进入 `未知演员/番号`。
- 未识别文件进入 `未知演员/未识别番号`。
- 同一影片的原片、分段与转码版本放入同一目录。
- 目标同名文件不会覆盖，只会跳过并报告。

确认前应仔细查看“可移动、跳过、清理目录”等分类。整理过程中可以停止后续移动，但已成功移动的文件不会自动回滚。

## 14. 独立工具箱

左侧“工具箱”与媒体库相互独立，可以从资源管理器拖入任意本地视频。

### 合并视频

- 支持拖入多个文件并调整顺序。
- 参数一致时可以无损合并。
- 参数不一致时可使用转码合并。
- 输出到第一段视频的同级目录，不覆盖已有文件。

### 转码视频

- 支持 H.264 NVENC 与 H.265/HEVC NVENC。
- 可选择保持原分辨率、720p 或 1080p。
- 可设置质量 CQ、最高码率和输出帧率。
- CQ 数值越小画质越高、文件通常越大。

### 媒体检测

拖入文件后使用 FFprobe 查看编码、分辨率、帧率、码率、音频和时长等参数。

工具箱与媒体库转码共享同一条 FFmpeg 队列，避免同时占用显卡和磁盘。

## 15. 局域网与手机连接

AVault 启动后会自动运行局域网服务。关闭主窗口后程序缩到托盘，服务仍保持运行；在托盘菜单选择“完全退出”才会停止。

设备首次连接时使用桌面端“连接手机”页面生成二维码。Android 客户端扫码后使用一次性凭据完成配对，并加密保存服务器身份、最近地址和设备令牌。再次启动时会先连接上次地址；电脑地址变化时，会通过局域网服务发现重新找到同一台服务器。

Android 端已完成以下功能：

- 媒体库、演员库和设置三个常驻页面，进入详情后返回可保留列表数据和滚动位置。
- 三列竖封网格与横封列表，分别显示番号或番号加标题；布局和排序偏好保存在本机。
- 独立搜索页：提交关键词前不请求影片数据，保存最近 10 条搜索历史，并支持片源分区、观看状态和发行日期筛选。
- 影片详情、演员资料、标签影片和社交链接浏览；观看状态由用户手动管理，并与桌面端同步。
- 原画、HEVC 原分辨率、720p HEVC 等可用文件版本选择，切换版本时保留当前进度。
- Media3 横屏播放器、续播和观看进度同步。
- 播放器手势：左/右半屏双击快退/快进 15 秒，横向拖动预览并在松手后跳转；左半屏纵向调节亮度；右半屏纵向调节音量；长按 2 倍速，保持长按向右滑切换 5 倍速，松手恢复正常速度。
- 倍速、双击跳转和拖动跳转使用顶部轻量提示，尽量不遮挡画面。

媒体流支持 HTTP Range，只允许通过服务端返回的文件 ID 访问。当前通信方式是局域网 HTTP 加 Bearer Token 鉴权，不提供公网访问、NAT 穿透或离线下载。Android 的详细使用和构建说明见 [`android/README.md`](android/README.md)。

## 16. 数据与备份

`AVault-data` 中主要保存：

- `avault.sqlite`：媒体库数据库、设置、观看状态和任务信息。
- `actors/`：演员头像。
- 应用日志、Cookie 和其他本机配置。

影片目录中主要保存：

- 原片与转码版本。
- `.avault-cover.*` 影片封面。
- `.avault-preview.jpg` 六宫格预览图。
- `.avault.json` 影片资料边车文件。

建议备份：

1. 对应磁盘根目录下的 `AVault-data`。
2. 各媒体目录中的 `.avault.json`、封面和预览图。

不要在 AVault 运行时直接替换 `avault.sqlite`。

## 17. 常见问题

### 扫描后出现未识别文件

进入左侧“未识别”页面，查看具体文件名。可以修改文件名后重新扫描，也可以进入详情页手动填写正确番号。

### 封面或演员头像不显示

确认对应图片文件仍存在，并检查媒体磁盘是否已连接。重新扫描不会自动重新下载已丢失的图片。

### FFmpeg 功能不可用

在 PowerShell 中执行：

```powershell
ffmpeg -version
ffprobe -version
ffmpeg -hide_banner -encoders | Select-String hevc_nvenc
```

前两条失败表示 FFmpeg 未加入系统 `PATH`；最后一条没有结果表示当前 FFmpeg 或显卡驱动不支持 NVIDIA HEVC 编码。

### PotPlayer 无法启动

进入“设置”，手动选择 PotPlayer 可执行文件，再回到详情页重新播放。

### 升级后看不到原数据

确认新版本是否安装到了另一块磁盘。AVault 默认读取当前安装盘根目录下的 `AVault-data`。

## 18. 开发与构建

### 桌面端

要求 Node.js 22、pnpm 10 和 Windows。

```powershell
cd electron
pnpm install
pnpm dev
```

常用检查：

```powershell
pnpm typecheck
pnpm test
pnpm build
```

生成 Windows NSIS 安装包：

```powershell
pnpm dist
```

安装包输出到 `electron/release/`。

### Android 端

要求 Android Studio、Android SDK 36 和可供 Android Gradle Plugin 9.1.1 使用的 JDK。当前最低系统版本为 Android 15（API 35）。

```powershell
cd android
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

调试 APK 输出到：

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

连接 Android 设备后可以安装：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
